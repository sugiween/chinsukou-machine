# ちんすこう 綴りの危うさ 可視化マシーン（非公式ブラウザ版）

レバーを倒すと「ち」「ん」「す」「こ」「う」の 5 つのリールが回り、綴りがシャッフルされます。

遊ぶ: https://sugiween.github.io/chinsukou-machine/

## 元ネタ

沖縄のウェブメディア DEEokinawa の特集記事で作られた実物のマシーンを、ブラウザで遊べる形に再現した非公式のファン作品です。箱、5 つの窓、レバーを倒すと文字が回る仕組みは、すべて元記事のアイデアと工作によるものです。

- 記事: [ちんすこうの文字の綴りの危うさを可視化するマシーンを作る](https://www.dee-okinawa.com/topics/2026/09/chinsukou.html)
- 著者: やんばるたろう さん
- 掲載: DEEokinawa（でぃーおきなわ）特集 2026.09.30
- X: [DEEokinawa の投稿](https://x.com/dee_okinawa/status/2105158969350090949)

DEEokinawa 編集部が制作・監修したものではありません。

## ブラウザ版で足したもの

判定スタンプ、危うさメーター、記録、効果音。実物のマシーンにはありません。出目は 5 つのリールそれぞれ 1/5 の乱数で、演出による操作はしていません。

## みんなの合計カウンター

公開ページ（sugiween.github.io）でだけ、回した回数と元記事へのリンクを押した回数を [Abacus](https://abacus.jasoncameron.dev/) に「1 足す」通信で数えています。手元で開いたときやコピー先では通信しません。自分の場所で数えたい場合は `index.html` の `COUNTER` の `host` と `ns` を自分のものに変えてください。

## レバーが折れる仕掛け

元記事へのリンクを一度も押していないブラウザでは、20 回回すとレバーが折れます。折れると「丈夫な本物を作りたいので記事を読む」と「直してつづける」の 2 つが出ます。前者を押すと元記事が開き、そのブラウザでは二度と折れません。後者を押すとその場で直って遊べます（また 20 回で折れます）。回数は `index.html` の `BREAK_AT` で変えられます。

## 使い方

`index.html` 1 ファイルで動きます。ダウンロードしてブラウザで開くか、好きな場所に置いてください。外部から読み込むのは Google Fonts の書体だけです。
